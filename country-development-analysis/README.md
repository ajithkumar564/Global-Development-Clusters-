# Country Development Indicators Analysis

## Business / Research Objective
Analyze country-level development indicators to understand relationships and differences in GDP, birth rate, and internet usage across countries and regions.

## Indicators
- GDP
- Birth Rate
- Internet Usage
- Country
- Region / Development Group where available

## Tools
- SQL
- Python
- pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Inspect country-level indicator data
2. Standardize field names and data types
3. Handle missing values and duplicates
4. Explore distributions and descriptive statistics
5. Use SQL for filtering, aggregation, grouping, and ranking
6. Compare countries/regions/development groups
7. Analyze relationships such as GDP vs internet usage
8. Create visualizations and document conclusions

## Key Questions
- Which countries have the highest and lowest GDP values in the selected dataset?
- How does internet usage vary across countries or regions?
- What patterns appear between GDP and internet usage?
- How does birth rate vary across development groups?
- Which regions show stronger or weaker indicator values?
- What data-quality limitations should be considered?

## Suggested Outputs
- GDP ranking
- Internet usage comparison
- Birth-rate comparison
- GDP vs internet usage scatter plot
- Correlation matrix
- Regional/development-group summary
