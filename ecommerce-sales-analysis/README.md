# E-commerce Sales & Customer Analytics

## Business Objective
Analyze e-commerce order data to identify revenue trends, average order value, product/category performance, and customer behavior that can support business decisions.

## Tools
- SQL
- Python
- pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Understand the business questions and dataset structure
2. Clean missing values, duplicates, and inconsistent records
3. Explore orders, customers, products, and dates with Python
4. Use SQL for KPI calculations, joins, rankings, and monthly trends
5. Visualize revenue, AOV, category performance, and customer behavior
6. Summarize findings as business recommendations

## Key Questions
- What is monthly revenue and how does it trend over time?
- What is the average order value?
- Which product categories contribute most to revenue?
- Which products perform strongly or weakly?
- How do new and repeat customers compare?
- Which months show weaker sales performance?

## Suggested KPIs
- Total Revenue
- Total Orders
- Total Customers
- Average Order Value (AOV)
- Revenue by Category
- Monthly Revenue
- Repeat Customer Rate
