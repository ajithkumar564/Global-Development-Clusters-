# Reliance Industries — Data Analyst Portfolio Project

## Project objective
Analyze publicly available Reliance Industries Limited (RIL) business and financial information to demonstrate an end-to-end data analyst workflow: data collection, cleaning, SQL analysis, Python EDA, KPI design, visualization, and Power BI dashboard planning.

## Source strategy
The primary source is RIL's official investor-relations and annual-report material. RIL publishes annual reports, quarterly results, financial presentations, and investor filings. The project should use official reported figures rather than invented or estimated values.

Official sources:
- RIL Financial Reporting: https://www.ril.com/investors/financial-reporting
- RIL Annual Reports: https://www.ril.com/investors/financial-reporting/online-annual-report
- RIL Investor Relations: https://www.ril.com/investors/investor-relations
- RIL LinkedIn: https://www.linkedin.com/company/reliance/

## Planned analysis
1. Consolidated revenue and EBITDA trend by financial year.
2. Profit after tax and capital expenditure trend.
3. Business-segment contribution and growth where segment-level data is available in the selected annual report.
4. Year-over-year growth calculations.
5. KPI cards and trend analysis in Power BI.
6. Optional public social-content analysis using manually collected metadata from official RIL/Jio public posts; social metrics will be clearly labeled as platform observations and will not be mixed with audited financial figures.

## Tools

## Data-quality rule
Do not fabricate financial values, social-media metrics, or business results. Every numerical result in the final report should be traceable to a source file and reporting period.
